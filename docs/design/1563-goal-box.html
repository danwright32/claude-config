#1563, the Goal accomplished box

For Dan, at the end of a session whose /goal was met or whose request is finished. Settled in one design round on 2026-10-24, where Dan chose option 3, Green border and heading, over a grey card, a green heading in a grey card, and a text box in the reply.

The settled design. The Claude Code terminal, which is itself the chrome of a mod. Every frame is drawn at its own width, from the committed fixture the built page renders too. The build is done when it scores 100% against this file on both halves.

Requirements

  • 1 When a /goal is met, or the work Dan asked for is finished, a box says GOAL ACCOMPLISHED, naming the goal.
  • 2 The box lists what shipped, one short line each: issues closed, pull requests merged and live.
  • 3 The box is green where the surface can render colour.

Decisions

  1. D1 The box is a card under the tool result row, its heading GOAL ACCOMPLISHED in bold. Dan chose a card over a text box in the reply, so it reads as the end of the session rather than more prose. Requirement 1. Checked on f1: a card holds the bold line GOAL ACCOMPLISHED.
  2. D2 The goal is the first line under the heading, in plain text. the box names the goal before what shipped. Requirement 1. Checked on f1: the line after GOAL ACCOMPLISHED is the goal, not coloured.
  3. D3 Each thing that shipped is its own line led by a bullet, the line itself plain. Dan settled on the goal plus a short list of what shipped (2026-10-23). Requirement 2. Checked on f1: each shipped line follows a bullet and is not coloured.
  4. D4 The card's border, the heading and the bullets are the success green; nothing else is coloured. Dan chose Green border and heading so the box reads at a glance as the end. Requirement 3. Checked on f1: the card's border, the heading and each bullet are green, and no other text is.

Exceptions Dan approved

None. A deliberate difference from this design is a new design round, or an exception Dan approves in his own words, recorded here.
