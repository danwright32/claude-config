#1583, a quiet background command after Claude stops

For Dan, reading the band above the prompt while a background command Claude started has printed nothing for a while. Settled in two design rounds on 2026-10-24: Dan chose to show it only once Claude's turn has ended, and option 3, Ask Claude to check, over Claude has stopped, Nobody watching, and Still running, Claude idle.

The settled design. The Claude Code terminal, which is itself the chrome of a mod. Every frame is drawn at its own width, from the committed fixture the built page renders too. The build is done when it scores 100% against this file on both halves.

Decisions

  1. D1 A background command of this conversation that has printed nothing for a while, or keeps repeating the same output, is not shown in the band while Claude is working; it shows only once Claude's turn has ended and it is still quiet. Claude's own job watcher reminder is unchanged. Dan: "if there's nothing for me to do, why do I need the notification at all?" While Claude works it is watching the command; once its turn ends, nobody is. No code: the rule is in the status bar's band, proven by its tests. Proven by payload/mods/status-bar/tests/register.test.tsx (a quiet background command shows only once Claude has stopped, and goes again when a turn runs) and payload/mods/status-bar/tests/facts.test.ts.
  2. D2 When it shows, the item reads the command's name, quiet, how long, then ask Claude to check, in amber. Dan chose option 3, Ask Claude to check: it says what he could do about it, in the place he would do it. No code: a wording decision of the band, read from the frame. Checked on f1: the band's amber item reads merge helper for #2733 quiet 12m, ask Claude to check.
  3. D3 Several such commands are each named, with ask Claude to check said once after them all. every fact once (L605): the action is the same for each. No code: proven by the status bar's tests. Proven by payload/mods/status-bar/tests/facts.test.ts (several quiet commands are each named, with ask Claude to check said once after them all).
  4. D4 Only this line changes: the quiet agent line and every other band wording stay as they were. Dan chose Just this line. No code: nothing is built for it. Proven by payload/mods/status-bar/tests/facts.test.ts (a quiet background agent is named with how long it has been quiet, ahead of the jobs; a background agent's jobs are one item under its name), unchanged by #1583.
  5. D5 While Claude is working, the band holds no item for the quiet command. D1, drawn. No code: the frame shows the absence. Checked on f2: the band holds no amber item while Claude is working.

Exceptions Dan approved

None. A deliberate difference from this design is a new design round, or an exception Dan approves in his own words, recorded here.
